# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want participation in this project to be a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal
appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and welcoming; assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Take responsibility for mistakes and learn from them.

## Unacceptable behavior

- Harassment, insults, or derogatory comments.
- Sexualized language or imagery, or unwelcome advances.
- Publishing others' private information without explicit permission.
- Any conduct that would reasonably be considered inappropriate in a
  professional setting.

## Scope

This code applies in all project spaces (issues, pull requests, discussions)
and when someone represents the project in public.

## Enforcement

Report unacceptable behavior privately to the maintainer,
[@aneudysamparo](https://github.com/aneudysamparo), through GitHub. All reports
are reviewed promptly and kept confidential. The maintainer may remove,
edit or reject contributions, or temporarily or permanently ban anyone whose
behavior breaks this code.
